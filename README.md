# VeinMinerPlus 使用说明

VeinMinerPlus 是一个支持普通连锁、范围挖掘、爆破采矿、批量交互和伐木的 Minecraft 模组。挖掘规则由服务端处理，玩家可以在游戏中切换模式，管理员可以调整数量、速度和搜索距离。

NeoForge 1.21.1 版本还提供矿石透视：用彩色空心方框标记选中的矿石，并支持为每个选择格设置颜色。

## 下载与安装

从 [GitHub Releases](https://github.com/GuHanDuRen/VeinMinerPLUS/releases/latest) 下载对应版本的 JAR。

| Minecraft | 加载器要求 | 当前 Mod 版本 | 矿石透视 |
| --- | --- | --- | --- |
| 1.21.1 | NeoForge 21.1.233 或更高的 1.21.1 版本 | 1.2.35 | 支持 |
| 1.20.1 | Forge 47.4.13 或更高的 1.20.1 版本 | 1.2.23 | 预留，尚未实现 |
| 1.12.2 | Forge 14.23.5.2860 或更高的 1.12.2 版本 | 1.2.21 | 预留，尚未实现 |

1. 安装与 Minecraft 版本对应的加载器。
2. 将对应 JAR 放入游戏实例的 `mods` 文件夹，同一实例只保留一份 VeinMinerPlus。
3. 多人游戏需要客户端和服务端都安装同一 Minecraft / 加载器分支的对应版本。
4. 使用 NeoForge 的透视矿石选择界面时，在客户端安装对应版本的 **JEI**，通过 JEI 物品列表拖入矿石。

三个分支的版本号和功能独立，下载时以 Minecraft 版本和加载器为准。

## 默认按键

| 操作 | 默认按键 / 用法 |
| --- | --- |
| 连锁挖掘 | 按住反引号键（键帽通常同时印有 `~`）并挖掘 |
| 切换模式 | 按住连锁键 + `Shift`，滚动鼠标滚轮 |
| 打开透视选择界面 | `'`，英文单引号键；仅 NeoForge 1.21.1 |
| 复制准星指向方块的 ID | 默认未指定，需要自行绑定 |
| 复制准星指向方块的矿物词典 / 矿石标签 | 默认未指定，需要自行绑定 |
| 确认添加白名单 | 进入白名单选择状态后按 `Enter` |
| 取消白名单选择 | `Esc` |

反引号键和单引号键是两个不同的按键：前者用于连锁，后者用于打开透视选择。

## 连锁模式

| 模式 | 用途 |
| --- | --- |
| 普通连锁 | 挖掘相邻的同一种方块，适合连续矿脉和原木。 |
| 交互连锁 | 按住连锁键，用手持物品右键批量操作相邻同种方块；也可用于连锁挖掘同种容器方块。 |
| 范围连锁 1×1 | 沿挖掘面的内侧方向继续挖掘同种方块。 |
| 范围连锁 3×3 / 5×5 | 按对应截面向内推进，处理与起始目标同种的方块，适合开挖通道。 |
| 爆破连锁：同类方块 | 在配置的搜索距离内寻找并继续挖掘同类目标；矿石可按矿石族规则匹配不同宿主岩石变种。 |
| 爆破连锁：所有矿石 | 挖掘识别到的矿石，以及管理员在额外目标白名单中添加的方块。 |
| 爆破连锁：所有可挖方块 | 扩展到可采集的非矿石方块，适合大范围清理。 |
| 爆破伐木：原木 | 搜索并挖掘原木。 |
| 透视模式 | 显示选中矿石的空心边框；当前仅 NeoForge 1.21.1 实现。 |

在 Minecraft 1.20.1 / 1.21.1 中，可在交互连锁模式下持斧头右键原木进行批量剥皮。其他物品能否批量操作，取决于其自身是否支持对目标方块使用。

挖掘仍受工具采集能力、服务端权限和其他模组的方块交互规则限制。普通和爆破模式会跳过容器；批量处理容器时使用交互连锁。

范围模式只处理匹配的同种方块，不会直接清空截面中的所有方块。爆破搜索可能从找到的目标继续扩展，搜索距离不是整次任务固定覆盖范围的承诺。

## 矿石透视与颜色设置

**适用版本：Minecraft 1.21.1 NeoForge。选择矿石需要客户端 JEI。**

1. 在世界中按 `'` 打开「透视矿石选择」，同时切换到透视模式。
2. 从右侧 JEI 列表把需要寻找的**矿石方块**拖入选择格。选择区共一行 9 格，记录的是筛选条件，不消耗实际物品。
3. 将鼠标放在某个格子上，按鼠标中键打开颜色设置。可用 RGB 滑块、HEX 色值或预设色调整颜色，然后点击「完成」。空格子也可以提前设置颜色。
4. 在矿石选择界面点击「完成」，返回世界查看彩色方框。
5. 找到矿石后，用「连锁键 + Shift + 滚轮」切换到所需的挖掘或爆破模式，再进行采集。透视模式本身只负责显示，不会自动爆破。

| 选择格操作 | 效果 |
| --- | --- |
| 从 JEI 拖入矿石 | 设置该格要显示的矿石方块 |
| 中键点击格子 | 修改该格的透视边框颜色 |
| 右键点击格子 | 移除矿石，保留格子颜色 |
| 在格子之间左键拖动 | 交换矿石，两个格子各自保留原来的颜色 |
| 点击「清空」 | 移除全部矿石选择，保留各格颜色 |

每个格子的默认颜色都不同。**颜色属于格子**：后续放进该格的矿石，都会使用该格设定的颜色显示。

透视按具体方块匹配。例如铀矿石、深板岩铀矿石和下界铀矿石需要分别选择，才会分别显示；不会因为选了其中一个就自动显示整类矿石。同一个方块放入多个格子时，使用最左侧格子的颜色。

当前透视扫描玩家附近已加载区块中的矿石，范围为 48 格，最多显示 2048 个方框。扫描逐步刷新；选择内容和颜色保存在客户端的 `config/veinminerplus-xray.json` 中。

## 管理员设置

在游戏聊天栏输入以下命令打开设置界面：

```text
/veinminerplus gui
```

需要权限等级 2（通常由服务器 OP 或单人世界开启作弊提供）。此界面修改的是服务端规则，保存后会影响服务器上的玩家；透视格子的颜色设置属于各自客户端。

可调整的项目包括普通 / 范围连锁数量与速度、爆破数量与速度、搜索距离、每 Tick 扫描区块数、低 TPS 自动降半径、饱食度消耗、默认模式和矿石爆破额外目标。

也可以通过命令查看或修改常用参数：

| 命令 | 作用 |
| --- | --- |
| `/veinminerplus blast-speed [数量]` | 查看或设置爆破每 Tick 的最大挖掘数量，最小为 1 |
| `/veinminerplus blast-distance [距离]` | 查看或设置爆破搜索距离，最小为 3 |
| `/veinminerplus blast-auto-radius [true/false]` | 查看或设置低 TPS 时自动降低爆破半径 |
| `/veinminerplus hunger-consumption [true/false]` | 查看或设置连锁挖掘是否消耗饱食度，`false` 表示免消耗 |

方括号表示可选参数，不要输入方括号；省略参数时查看当前值。挖掘速度较慢时，分别检查普通模式和爆破模式的每 Tick 数量；大范围爆破还受扫描速度与服务器性能影响。

### 矿石爆破额外目标

白名单只为「爆破连锁：所有矿石」**追加目标**，不会替换原有矿石识别规则，也不会更改透视格子的筛选条件。

- 在设置界面中每行填写一条规则，可使用方块 ID（如 `minecraft:clay`）或 `*` 通配符。
- NeoForge 1.21.1 和 Forge 1.20.1 还支持 `#方块标签`，例如各自环境中存在的 `#c:ores` 或 `#forge:ores`。
- Forge 1.12.2 使用矿物词典写法，例如 `ore:oreCopper`。
- 点击白名单旁的 `+`，对准世界中的方块，按 `Enter` 添加；按 `Esc` 取消。每行右侧的 `-` 用于删除规则。
- 返回设置界面后点击「完成」保存。
