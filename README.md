# VeinMinerPlus 使用说明

VeinMinerPlus 是一个支持普通连锁、范围挖掘、爆破采矿、批量交互和伐木的 Minecraft 模组。挖掘规则由服务端处理，玩家可以在游戏中切换模式，管理员可以调整数量、速度和搜索距离。

NeoForge 1.21.1 版本还提供矿石透视：用彩色空心方框标记选中的矿石，并支持为每个选择格设置颜色。

## 下载与安装

从 [GitHub Releases](https://github.com/GuHanDuRen/VeinMinerPLUS/releases/latest) 下载对应版本的 JAR。

## 默认按键

| 操作 | 默认按键 / 用法 |
| --- | --- |
| 连锁挖掘 | 按住反引号键（键帽通常同时印有 `~`）并挖掘 |
| 跳过 AE 存储入库 | 默认按住 `Shift` + 连锁键挖掘，可在按键设置中重新绑定 |
| 切换模式 | 按住连锁键 + `Shift`，滚动鼠标滚轮 |
| 打开透视选择界面 | `'`，英文单引号键；仅 NeoForge 1.21.1 |
| 复制准星指向方块的 ID | 默认未指定，需要自行绑定 |
| 复制准星指向方块的矿物词典 / 矿石标签 | 默认未指定，需要自行绑定 |
| 确认添加白名单 / 黑名单 | 进入对应名单的选择状态后按 `Enter` |
| 取消名单选择 | `Esc` |

反引号键和单引号键是两个不同的按键：前者用于连锁，后者用于打开透视选择。

## 连锁模式

| 模式 | 用途 |
| --- | --- |
| 普通连锁 | 挖掘相邻的同一种方块，适合连续矿脉和原木。 |
| 交互连锁 | 按住连锁键，用手持物品右键批量操作相邻同种方块；也可用于连锁挖掘同种容器方块。 |
| 范围连锁 1×1 | 沿挖掘面的内侧方向继续挖掘同种方块。 |
| 范围连锁 3×3 / 5×5 | 按对应截面向内推进，处理与起始目标同种的方块，适合开挖通道。 |
| 爆破连锁：同类方块 | 在配置的搜索距离内寻找并继续挖掘同类目标；矿石可按矿石族规则匹配不同宿主岩石变种。 |
| 爆破连锁：所有矿石 | 挖掘识别到的矿石，以及管理员在额外目标白名单中添加的方块。 |
| 爆破连锁：所有可挖方块 | 扩展到可采集的非矿石方块，适合大范围清理。 |
| 爆破伐木：原木 | 搜索并挖掘原木。 |
| 透视模式 | 显示选中矿石的空心边框；当前仅 NeoForge 1.21.1 实现。 |

在 Minecraft 1.20.1 / 1.21.1 中，可在交互连锁模式下持斧头右键原木进行批量剥皮。其他物品能否批量操作，取决于其自身是否支持对目标方块使用。

挖掘仍受工具采集能力、服务端权限和其他模组的方块交互规则限制。普通和爆破模式会跳过容器；批量处理容器时使用交互连锁。

范围模式只处理匹配的同种方块，不会直接清空截面中的所有方块。爆破搜索可能从找到的目标继续扩展，搜索距离不是整次任务固定覆盖范围的承诺。

## AE 存储与连锁掉落

携带装有磁力卡的无线终端时，连锁挖掘的物品掉落会尝试直接进入终端连接的 AE 存储，并遵守磁力卡的开关、过滤规则和无线连接条件。

- NeoForge 1.21.1 / Forge 1.20.1 需要同时安装 AE2 和可选扩展 AE2 Wireless Terminals（AE2WTLib），并启用磁力卡的「拾取至 ME」模式。
- Forge 1.12.2 支持 AE2UEL 内置的磁力卡；原版 AE2 rv6 没有这一内置功能。
- 默认按住 `Shift` + 连锁键挖掘时跳过 AE 入库，掉落放在玩家脚下。此快捷键可在按键设置中更改。
- 存储空间不足、网络不可用或过滤规则不允许存入时，未存入的物品仍放在玩家脚下；空间只够一部分时只存入可接收的数量。
- NeoForge 1.21.1 / Forge 1.20.1 的剩余连锁掉落不会再被无线终端的自动拾取二次存入 ME；NeoForge 的补货功能也不会绕过「拾取至 ME」开关。

未安装对应 AE 扩展或没有有效磁力卡终端时，连锁掉落沿用普通行为。经验仍留在玩家脚下。

## 矿石透视与颜色设置

**适用版本：Minecraft 1.21.1 NeoForge。选择矿石需要客户端 JEI。**

1. 在世界中按 `'` 打开「透视矿石选择」，同时切换到透视模式。
2. 从右侧 JEI 列表把需要寻找的**矿石方块**拖入选择格。选择区共一行 9 格，记录的是筛选条件，不消耗实际物品。
3. 将鼠标放在某个格子上，按鼠标中键打开颜色设置。可用 RGB 滑块、HEX 色值或预设色调整颜色，然后点击「完成」。空格子也可以提前设置颜色。
4. 在矿石选择界面点击「完成」，返回世界查看彩色方框。
5. 找到矿石后，用「连锁键 + Shift + 滚轮」切换到所需的挖掘或爆破模式，再进行采集。透视模式本身只负责显示，不会自动爆破。

| 选择格操作 | 效果 |
| --- | --- |
| 从 JEI 拖入矿石 | 设置该格要显示的矿石方块 |
| 中键点击格子 | 修改该格的透视边框颜色 |
| 右键点击格子 | 移除矿石，保留格子颜色 |
| 在格子之间左键拖动 | 交换矿石，两个格子各自保留原来的颜色 |
| 点击「清空」 | 移除全部矿石选择，保留各格颜色 |

每个格子的默认颜色都不同。**颜色属于格子**：后续放进该格的矿石，都会使用该格设定的颜色显示。

透视按具体方块匹配。例如铀矿石、深板岩铀矿石和下界铀矿石需要分别选择，才会分别显示；不会因为选了其中一个就自动显示整类矿石。同一个方块放入多个格子时，使用最左侧格子的颜色。

当前透视扫描玩家附近已加载区块中的矿石，范围为 48 格，最多显示 2048 个方框。扫描逐步刷新；选择内容和颜色保存在客户端的 `config/veinminerplus-xray.json` 中。

## 管理员设置

在游戏聊天栏输入以下命令打开设置界面：

```text
/veinminerplus gui
```

需要权限等级 2（通常由服务器 OP 或单人世界开启作弊提供）。此界面修改的是服务端规则，保存后会影响服务器上的玩家；透视格子的颜色设置属于各自客户端。

可调整的项目包括普通 / 范围连锁数量与速度、爆破数量与速度、搜索距离、每 Tick 扫描区块数、低 TPS 自动降半径、饱食度消耗、默认模式、矿石爆破额外目标和全模式方块黑名单。

以上参数统一在 `/veinminerplus gui` 设置界面中查看和修改。需要排查连锁问题时，可使用以下命令控制服务端调试日志：

```text
/veinminerplus debug true
/veinminerplus debug false
```

`true` 开启，`false` 关闭，均需要权限等级 2，也可从服务端控制台执行。命令对应配置文件中的 `debugLogging` 开关，保存后立即生效，无需重启；默认关闭。NeoForge 1.21.1 / Forge 1.20.1 保存为 `debugLogging = true|false`，Forge 1.12.2 保存为 `chain_mining` 下的 `B:debugLogging=true|false`。调试信息写入服务端日志中的 `[chain-debug]` 条目。

挖掘速度较慢时，分别检查普通模式和爆破模式的每 Tick 数量；大范围爆破还受扫描速度与服务器性能影响。

### 矿石爆破额外目标

白名单只为「爆破连锁：所有矿石」**追加目标**，不会替换原有矿石识别规则，也不会更改透视格子的筛选条件。

- 在设置界面中每行填写一条规则，可使用方块 ID（如 `minecraft:clay`）或 `*` 通配符。
- NeoForge 1.21.1 和 Forge 1.20.1 还支持 `#方块标签`，例如各自环境中存在的 `#c:ores` 或 `#forge:ores`。
- Forge 1.12.2 使用矿物词典写法，例如 `ore:oreCopper`。
- 点击白名单旁的 `+`，对准世界中的方块，按 `Enter` 添加；按 `Esc` 取消。每行右侧的 `-` 用于删除规则。
- 返回设置界面后点击「完成」保存。

### 全模式方块黑名单

黑名单默认为空，优先于矿石识别和白名单，所有普通连锁、范围、爆破、伐木和批量右键模式都会跳过其中的方块；NeoForge 的透视扫描和显示也遵守黑名单。普通单块手动挖掘和单次右键交互不受影响。

在 `/veinminerplus gui` 的「全模式方块黑名单」中每行填写一条规则，格式与白名单相同：方块 ID、`*` 通配符、现代版本的 `#方块标签` 或 1.12.2 的 `ore:矿物词典条目`。点击黑名单旁的 `+`，对准方块后按 `Enter` 添加具体方块 ID；每行的 `-` 删除规则。

点击「完成」保存后，服务端黑名单同步给所有在线玩家，并立即参与正在运行的任务判定。新加入的玩家自动收到服务端规则，无需打开管理员设置界面。

### 配置文件位置

以下路径均相对于对应的游戏实例或服务端目录。多人游戏的挖掘参数以服务端配置为准。

| 用途 | 文件 |
| --- | --- |
| NeoForge 1.21.1 / Forge 1.20.1 连锁规则 | `config/veinminerplus-common.toml` |
| Forge 1.12.2 连锁规则 | `config/veinminerplus.cfg` |
| NeoForge 客户端透视选择与颜色 | `config/veinminerplus-xray.json` |
| NeoForge 1.21.1 / Forge 1.20.1 客户端启动动画 | `config/veinminerplus-client.toml` |
| Forge 1.12.2 客户端启动动画 | `config/veinminerplus-client.cfg` |

三个版本的客户端启动动画默认开启，使用模组内置 GIF 替换原生启动图标：NeoForge 的小狐狸、Forge 1.20.1 的铁砧和 Forge 1.12.2 的 Forge 标志。

Forge 1.20.1 在模组发现阶段接管动画，窗口刚出现时可能短暂显示原生铁砧。

NeoForge 1.21.1 / Forge 1.20.1 的开关为 `customStartupAnimation = true`；Forge 1.12.2 的开关为客户端配置中的 `B:customStartupAnimation=true`。改为 `false` 后，下次启动游戏恢复对应版本的原生图标。
